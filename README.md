# sfidaperinglesefacile

Repository con due prototipi statici (HTML/CSS/JS, nessun backend richiesto — basta aprire il file `index.html` in un browser o servirlo come sito statico):

- **`/index.html`** — Prototipo "Nelson & Ada", assessment e lezioni di inglese basate su AI.
- **`/vendite/index.html`** — **SalesHub**, app per la rete vendita: gestione prospect (pipeline a kanban, elenco, note di attività) per i venditori, più un archivio materiali di vendita caricabile e gestibile dall'area Amministrazione.

⚠️ Entrambi i prototipi salvano i dati solo nel `localStorage` del browser: utili per validare il flusso d'uso, ma senza sincronizzazione tra utenti/dispositivi. Per un utilizzo reale con più venditori serve un backend condiviso (autenticazione vera, database, storage file lato server).
